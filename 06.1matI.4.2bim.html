📏 Capítulo 4: Função Afim

"A função afim modela relações lineares entre duas grandezas. Com ela, podemos prever, analisar e decidir."

BNCC: EM13MAT101, EM13MAT105, EM13MAT302, EM13MAT314, EM13MAT401, EM13MAT404, EM13MAT501, EM13MAT510

📖 4.1 Função polinomial do 1º grau ou função afim

Uma função afim (ou função polinomial do 1º grau) é toda função f: ℝ → ℝ que pode ser escrita na forma:

f(x) = ax + b, com a, b ∈ ℝ e a ≠ 0
  • a é o coeficiente angular (determina a inclinação da reta).
  • b é o coeficiente linear (determina o ponto onde a reta cruza o eixo y).
  • O gráfico de uma função afim é uma reta.
  • O domínio e a imagem são todos os números reais (ℝ).
Exemplos:
• f(x) = 2x + 3 (a = 2, b = 3)
• f(x) = –x + 5 (a = –1, b = 5)
• f(x) = 4x (a = 4, b = 0) — função linear (caso particular da afim)

Observação: Quando b = 0, a função é chamada de função linear. Quando a = 0, a função é constante (não é afim).

💡 "Toda função linear é afim, mas nem toda afim é linear."

📊 4.2 Variação da função afim

▶ Classificação quanto ao crescimento

Sinal de aComportamentoGráfico
a > 0Função crescenteReta inclinada para cima (↗)
a < 0Função decrescenteReta inclinada para baixo (↘)
a = 0Função constante (não é afim)Reta horizontal (→)

Altere o valor de a no gráfico interativo acima e observe a mudança na inclinação da reta.

▶ Taxa de variação

A taxa de variação de uma função afim é constante e igual ao coeficiente angular a:

Δy / Δx = (f(x₂) – f(x₁)) / (x₂ – x₁) = a

Isso significa que, para cada aumento de 1 unidade em x, o valor de y aumenta (ou diminui) exatamente a unidades.

Exemplo: Na função f(x) = 3x – 2, a taxa de variação é a = 3. Assim, quando x aumenta 1, y aumenta 3. Quando x aumenta 2, y aumenta 6.

▶ Zero da função afim

O zero da função é o valor de x que torna f(x) = 0. Para a função f(x) = ax + b, temos:

x = –b / a (com a ≠ 0)

Geometricamente, é a abscissa do ponto onde a reta cruza o eixo x.

⚖️ 4.3 Inequação-produto e inequação-quociente

▶ Estudo do sinal da função afim

O sinal da função f(x) = ax + b depende do sinal de a e do zero da função (x₀ = –b/a).

  • Se a > 0 (função crescente):
    • f(x) < 0 para x < x₀
    • f(x) = 0 para x = x₀
    • f(x) > 0 para x > x₀
  • Se a < 0 (função decrescente):
    • f(x) > 0 para x < x₀
    • f(x) = 0 para x = x₀
    • f(x) < 0 para x > x₀
Exemplo: Para f(x) = 2x – 6, a = 2 > 0 e x₀ = 3.
• f(x) < 0 para x < 3
• f(x) > 0 para x > 3

▶ Inequação-produto

Uma inequação-produto é do tipo f(x) · g(x) > 0 (ou ≥, <, ≤). Para resolvê-la, estuda-se o sinal de cada função separadamente e aplica-se a regra dos sinais (sinais iguais ⇒ positivo; sinais diferentes ⇒ negativo).

Exemplo resolvido: (x – 2)(x + 3) > 0
f(x) = x – 2 ⇒ zero em x = 2 (a=1>0 ⇒ crescente)
g(x) = x + 3 ⇒ zero em x = –3 (a=1>0 ⇒ crescente)
IntervaloSinal de fSinal de gSinal do produto
x < –3––+
–3 < x < 2–+–
x > 2+++
Solução: S = {x ∈ ℝ | x < –3 ou x > 2}

▶ Inequação-quociente

Uma inequação-quociente é do tipo f(x) / g(x) > 0 (ou ≥, <, ≤), com g(x) ≠ 0. A resolução é análoga à inequação-produto, mas deve-se excluir os valores que anulam o denominador.

Exemplo resolvido: (x – 1) / (x + 2) ≥ 0
f(x) = x – 1 ⇒ zero em x = 1 (crescente)
g(x) = x + 2 ⇒ zero em x = –2 (crescente, mas não pode ser igual a 0)
IntervaloSinal de fSinal de gSinal do quociente
x < –2––+
–2 < x < 1–+–
x > 1+++
Solução: S = {x ∈ ℝ | x < –2 ou x ≥ 1} (nota: x = –2 está excluído)

🔍 Guia dos Coeficientes da Função Afim

Entenda exatamente o que cada coeficiente faz no gráfico. Use os controles acima para testar enquanto lê.

📐 Coeficiente a (angular)

Controla a inclinação da reta.

  • a > 0 → reta sobe (crescente).
  • a < 0 → reta desce (decrescente).
  • a = 0 → reta horizontal (constante).
  • Quanto maior o |a|, mais íngreme a reta.
  • Taxa de variação: para cada +1 em x, y varia em a.

📍 Coeficiente b (linear)

Define o ponto onde a reta cruza o eixo y.

  • Quando x = 0, f(0) = b → ponto (0, b).
  • b > 0 → corta acima da origem.
  • b < 0 → corta abaixo da origem.
  • b = 0 → reta passa pela origem.
  • Alterar b desloca a reta verticalmente sem mudar a inclinação.

✏️ Exercícios

1. Dada a função f(x) = 3x – 12, determine:
a) O zero da função.
b) O ponto onde a reta corta o eixo y.
c) O valor de x para que f(x) = 6.
d) Classifique a função como crescente ou decrescente.
2. Resolva a inequação: (2x – 4)(x + 1) ≤ 0.
3. Determine a lei da função afim que passa pelos pontos A(2, 5) e B(4, 9).
4. Resolva a inequação-quociente: (x + 3) / (x – 1) > 0.
5. Uma empresa cobra uma taxa fixa de R$ 50,00 mais R$ 2,00 por quilômetro rodado. Escreva a função que representa o custo total C(x) em função da distância x (em km).

Respostas: 1a) x=4; 1b) (0,-12); 1c) x=6; 1d) crescente. 2) S = {x ∈ ℝ | –1 ≤ x ≤ 2}. 3) f(x) = 2x + 1. 4) S = {x ∈ ℝ | x < –3 ou x > 1}. 5) C(x) = 2x + 50.
