🔄 Capítulo 5: Função Quadrática

"A função quadrática descreve movimentos parabólicos e nos ajuda a encontrar máximos e mínimos."

BNCC: EM13MAT302, EM13MAT402, EM13MAT502, EM13MAT503

📖 5.1 Função quadrática

Uma função quadrática (ou função polinomial do 2º grau) é toda função f: ℝ → ℝ que pode ser escrita na forma:

f(x) = ax² + bx + c, com a, b, c ∈ ℝ e a ≠ 0
  • a define a concavidade e a abertura da parábola.
  • b influencia a posição do vértice e a simetria.
  • c é o ponto onde a parábola cruza o eixo y (0, c).
  • O gráfico é uma parábola.
Exemplos:
• f(x) = x² – 4x + 3 (a=1, b=-4, c=3)
• f(x) = –2x² + 4x (a=-2, b=4, c=0)
• f(x) = x² – 9 (a=1, b=0, c=-9)

Observação: Se a = 0, a função deixa de ser quadrática e torna-se afim (ou constante).

🔝 5.2 Otimização da função quadrática

▶ Vértice da parábola

O vértice é o ponto de máximo ou mínimo da função quadrática. Suas coordenadas são:

xv = –b / (2a)    e    yv = –Δ / (4a)

onde Δ = b² – 4ac (discriminante).

  • Se a > 0, a parábola tem concavidade para cima e o vértice é um ponto de mínimo.
  • Se a < 0, a parábola tem concavidade para baixo e o vértice é um ponto de máximo.
Exemplo: Para f(x) = x² – 4x + 3, temos a=1, b=-4, c=3.
xv = –(–4)/(2·1) = 2
yv = f(2) = 2² – 4·2 + 3 = 4 – 8 + 3 = –1
Vértice: (2, –1) – ponto de mínimo.

▶ Conjunto imagem

A imagem da função quadrática depende do sinal de a e do vértice:

  • Se a > 0: Im = [yv, ∞)
  • Se a < 0: Im = (–∞, yv]
Exemplo: Para f(x) = –2x² + 8x – 6 (a=-2, b=8, c=-6):
xv = –8/(2·(-2)) = –8/–4 = 2
yv = f(2) = –2·4 + 16 – 6 = –8 + 10 = 2
Vértice: (2,2) – ponto de máximo.
Imagem: Im = (–∞, 2]

⚖️ 5.3 Inequações polinomiais do 2º grau

Uma inequação do 2º grau é da forma ax² + bx + c > 0 (ou ≥, <, ≤), com a ≠ 0.

Para resolvê-la, estuda-se o sinal da função quadrática. O sinal depende do discriminante (Δ) e do sinal de a.

▶ Estudo do sinal

  • Se Δ > 0 (duas raízes reais distintas: x₁ < x₂):
    f(x) tem o sinal de a para x < x₁ e x > x₂, e sinal contrário para x₁ < x < x₂.
  • Se Δ = 0 (uma raiz dupla: x₀):
    f(x) tem o sinal de a para todo x ≠ x₀, e f(x₀) = 0.
  • Se Δ < 0 (nenhuma raiz real):
    f(x) tem o sinal de a para todo x ∈ ℝ.
Exemplo resolvido: x² – 5x + 6 > 0
a=1 > 0, Δ = 25 – 24 = 1 > 0, raízes: x₁=2, x₂=3.
Para x < 2 ou x > 3, f(x) > 0. Para 2 < x < 3, f(x) < 0.
Solução: S = {x ∈ ℝ | x < 2 ou x > 3}
Exemplo resolvido: –x² + 4x – 4 ≤ 0
a=-1 < 0, Δ = 16 – 16 = 0, raiz dupla: x₀ = 2.
Para todo x ≠ 2, f(x) < 0 (sinal de a), e f(2)=0.
Solução: S = ℝ (todos os reais)

🔍 Guia dos Coeficientes da Função Quadrática

Entenda exatamente o que cada coeficiente faz no gráfico. Use os controles acima para testar enquanto lê.

🔄 Coeficiente a (quadrático)

Define a concavidade e a abertura da parábola.

  • a > 0 → concavidade para cima ∪ (mínimo).
  • a < 0 → concavidade para baixo ∩ (máximo).
  • |a| grande → parábola mais fechada.
  • |a| pequeno → parábola mais aberta.
  • Se a = 0, deixa de ser quadrática.

↔️ Coeficiente b (linear)

Desloca o vértice horizontalmente e influencia a simetria.

  • A coordenada x do vértice é xv = –b/(2a).
  • Se b = 0, o vértice está sobre o eixo y.
  • b ≠ 0 desloca o vértice para esquerda ou direita.
  • Afeta a posição das raízes e o formato geral.

📍 Coeficiente c (constante)

Ponto de interseção com o eixo y.

  • f(0) = c → ponto (0, c).
  • Alterar c sobe ou desce a parábola inteira.
  • Não altera a posição horizontal do vértice (xv permanece).
  • Mudanças em c podem fazer a parábola ganhar ou perder raízes.

💡 Conexão importante: O discriminante Δ = b² – 4ac determina quantas raízes reais a parábola possui: Δ > 0 → duas raízes; Δ = 0 → uma raiz dupla; Δ < 0 → nenhuma raiz real.

✏️ Exercícios

1. Dada a função f(x) = x² – 6x + 8, determine:
a) As raízes da função.
b) As coordenadas do vértice.
c) O conjunto imagem.
2. Resolva a inequação: –x² + 5x – 6 ≤ 0.
3. Determine o valor máximo da função f(x) = –2x² + 12x – 10.
4. Esboce o gráfico da função f(x) = x² – 4x + 4 e determine seu zero.
5. Uma bola é lançada verticalmente para cima com altura dada por h(t) = –5t² + 20t (em metros, t em segundos). Calcule a altura máxima atingida e o tempo para atingi-la.

Respostas: 1a) x=2 e x=4; 1b) (3,-1); 1c) [–1, ∞). 2) S = {x ∈ ℝ | x ≤ 2 ou x ≥ 3}. 3) 8. 4) Zero duplo em x=2. 5) Altura máxima = 20 m, tempo = 2 s.
